## 🔒 Pourquoi choisir Notaway ?

**Notaway** fusionne en une seule application native Windows le meilleur des outils de référence : la fluidité de prise de notes de **Notion**, la souveraineté locale d'**Obsidian**, la gestion de flux de **Trello** et la liberté visuelle de **Miro**.

* 🛡️ **100% Local & Zéro Cloud** : Vos notes, tableaux, canvas et données sont enregistrés directement sur votre disque dur dans des formats ouverts (`.md`, `.json`, `.csv`, images). Pas de compte, pas de télémétrie, zéro dépendance réseau. Vos créations vous appartiennent pour toujours.
* ⚡ **Performance Native & Légèreté** : Conçu sur un cœur natif en **Rust (Tauri v2)** et une interface React soignée. Consommation minimale de RAM, démarrage instantané et réactivité fluide à 144 Hz.
* 📦 **Interopérabilité & Formats Ouverts** : Vos fichiers sont lisibles dans n'importe quel éditeur externe (VS Code, Obsidian, Excel). Export Markdown épuré (sans métadonnées), export CSV universel et export PNG Retina 2x.
* 💾 **Sécurité & Sauvegardes Intégrées** : Sauvegarde et restauration complète de votre espace en archive `.zip` en un seul clic. Corbeille locale sécurisée (`.trash`) pour prévenir toute perte accidentelle.
* 🔄 **Mises à jour transparentes** : Détection automatique des nouvelles versions publiées sur GitHub et mise à jour en un clic.

## 🚀 Prise en main en 30 secondes

1. **Téléchargez** la dernière version : **[Notaway_x.x.x_x64-setup.exe](https://github.com/ANKY3D/notaway-releases/releases/latest)**.
2. **Lancez l'installateur** : l'installation s'effectue en quelques secondes sur Windows 10 ou 11 (aucun droit administrateur nécessaire).
3. **Choisissez votre dossier de travail** : au premier lancement, sélectionnez simplement le répertoire de votre disque dur où vous souhaitez ranger vos documents (disque local, dossier synchronisé personnel, etc.).
4. **C'est tout !** Votre espace de travail est prêt, 100% sécurisé et immédiatement opérationnel.

## ⌨️ Raccourcis Clés

| Raccourci | Action |
| :--- | :--- |
| <kbd>Ctrl</kbd> + <kbd>K</kbd> | Ouvrir la recherche universelle instantanée |
| <kbd>Ctrl</kbd> + <kbd>B</kbd> | Rétracter / Déployer la barre latérale |
| <kbd>Ctrl</kbd> + <kbd>E</kbd> | Exporter le Canvas actuel en image PNG HD (Retina) |
| <kbd>Ctrl</kbd> + <kbd>Z</kbd> / <kbd>Ctrl</kbd> + <kbd>Y</kbd> | Annuler / Rétablir l'action (Canvas & Éditeur) |
| <kbd>/</kbd> | Ouvrir le menu des commandes rapides dans l'éditeur de notes |
| <kbd>F11</kbd> | Basculer en mode Plein Écran sans distraction |
