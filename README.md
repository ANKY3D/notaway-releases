## 🔒 Why Notaway?

**Notaway** merges the very best modern productivity tools into a single, high-performance native Windows application: the rich document writing of **Notion**, the local sovereignty and longevity of **Obsidian**, the visual task flow of **Trello**, and the infinite creative whiteboard of **Miro**.

* 🌐 **Full Bilingual Support (English & Français)**: Native English and French support with automatic system language detection and instant 1-click toggling.
* 🛡️ **100% Local & Zero Cloud**: Your notes, boards, canvases, and data live exclusively on your hard drive in open formats (`.md`, `.json`, `.csv`, images). No account, no telemetry, zero network dependency. Your work belongs to you forever.
* ⚡ **Blazing Fast Native Performance**: Built on a high-efficiency **Rust (Tauri v2)** native core with a polished React frontend. Ultra-low RAM usage, instant cold startup, and fluid 144 Hz responsiveness.
* 📦 **Interoperability & Open Formats**: Easily read and edit your files in external tools (VS Code, Obsidian, Excel). Clean Markdown export, universal CSV data tables, and Retina 2x PNG rendering.
* 💾 **Integrated Backups & Security**: One-click `.zip` workspace archive and restore. Built-in local safe-trash (`.trash`) to protect against accidental deletions.
* 🔄 **Seamless Auto-Updates**: Automatic background check for new releases on GitHub with painless 1-click updates.

## 🚀 Getting Started in 30 Seconds

1. **Visit [notaway.fr](https://notaway.fr)** or directly download the Windows installer: **[Notaway_0.7.6_x64-setup.exe](https://github.com/ANKY3D/notaway-releases/releases/latest)**.
2. **Run the installer**: Installs in seconds on Windows 10 or 11 (no admin privileges required).
3. **Choose your workspace directory**: On first launch, pick any local directory where you want to keep your documents (local SSD, personal synced drive, etc.).
4. **You're all set!** Your private, bilingual, offline workspace is instantly ready.

## ⌨️ Key Shortcuts

| Shortcut | Action |
| :--- | :--- |
| <kbd>Ctrl</kbd> + <kbd>K</kbd> | Open instant universal search |
| <kbd>Ctrl</kbd> + <kbd>B</kbd> | Collapse / Expand sidebar |
| <kbd>Ctrl</kbd> + <kbd>E</kbd> | Export current Canvas as HD PNG (Retina) |
| <kbd>Ctrl</kbd> + <kbd>F</kbd> | Find & Replace in Mini-IDE |
| <kbd>Ctrl</kbd> + <kbd>Z</kbd> / <kbd>Ctrl</kbd> + <kbd>Y</kbd> | Undo / Redo action (Canvas & Editor) |
| <kbd>/</kbd> | Open quick slash command menu in Notes |
| <kbd>F11</kbd> | Toggle distraction-free Fullscreen mode |
